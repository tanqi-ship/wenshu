# M4.1：问数可答性判定

日期：2026-11-25。本文定义待实施的设计。

## 目标与接入位置

区分“明确提出的指标未登记”与“已登记指标的查询超出当次权限”，同时保留澄清、空结果与技术失败各自的含义。不新增模型调用，不依据置信分数或向量距离判定，也不在编译前复制明细、JOIN、报表和占比的来源与权限逻辑。

在 `QueryService._finish` 的编译调用处增加窄范围映射，问数调用方可复用，编译器与独立校验器的契约不变。非 `slots_complete` 的会话保持原样；槽位齐全后仍要求显式 `Scope`。成功编译的 SQL 继续经过 L4，只有通过才执行。M4.1 不新增提前放行的结果，也不改会话持久化、模型提示词或回放协议。

## 判定规则

| 条件 | 问数入口行为 |
|---|---|
| 尚待补充指标或时间，或会话要求重述、重启或停止 | 返回现有会话结果，不进入编译 |
| L3 报出 `symbol_table / UNKNOWN_METRIC` | `UNANSWERABLE`：当前不支持查询该指标。使用语义目录已有的指标、编码和同义词解析结果；不把 `intent / UNKNOWN_METRIC` 认作目录未命中 |
| L3 报出 `scope / METRIC_OUT_OF_SCOPE`、`scope / TABLE_NOT_IN_SCOPE` 或 `scope / COLUMN_NOT_IN_SCOPE` | `OUT_OF_SCOPE`：当前权限无法完成该查询。列来源无法确认时按现有权限规则拒绝 |
| 其他编译异常、SQL 校验问题或数据库失败 | 保持现有失败分类与阻断行为，不按异常文本推断，也不将 L4 的同名问题码混入 L3 映射 |
| SQL 执行成功，结果为空或聚合值为 `NULL` | 正常返回数据结果，不推断为不可答或越权 |

只匹配表中明确列出的 L3 阶段和错误码组合；未知维度、未登记码值、缺来源、报表缺分区和不支持的查询形状均不在本次转换范围。沿用编译器现有检查顺序：例如已明确的指标未登记时，即使 `Scope` 为空，也先得到 `UNANSWERABLE`。保留按当次行策略缩小查询范围的行为，不为判定而扩大权限、再次编译或试查数据库。

## 返回契约

- `start` 和 `reply` 继续返回现有 `SessionResult` 或 `QueryAnswer`，新增独立的业务拒绝结果，字段为 `code`、固定中文 `message`、`session_id` 和 `version`。
- 新结果不携带完整会话、Intent、模型响应、内部异常、物理表列名或 SQL。映射成功即停止，不调用 L4 或 L5。会话仍按原流程先保存，后续判定不会把已结束会话改回待补答。
- `demo_query` 为两类业务拒绝输出 JSON 并退出 `0`，与现有正常澄清结果一致；调用方通过 `code` 区分业务拒绝与查询成功。技术错误仍按现有方式退出非零。直接调用编译器仍可获得原始 `CompileError`。

## 离线验收

- 复用 `EX-009` 严格回放验证 `UNANSWERABLE`，保留原 cassette；用 `AQ-001` 的显式空表范围和限制列范围分别验证 `OUT_OF_SCOPE`，断言返回不含物理表列名。
- 覆盖主表、附加表和列权限的错误码映射，验证拒绝分支不调用 L4/L5；补答路径用当次权限验证同一分类逻辑。
- 验证待澄清、正常结果、空结果和 `NULL` 沿用原契约，未知编译错误、校验失败和执行超时不会被转换。运行现有全量测试、Ruff 和黄金 SQL 门禁，不调用真实模型，不修改 M4.2 评测集。
